# Todo List Application

A Django-based Todo List application that helps you manage tasks and organize them with tags.

## Features

- **Task Management**: Create, read, update, and delete tasks
- **Task Status**: Mark tasks as complete/incomplete with toggle functionality
- **Deadlines**: Set optional deadlines for tasks
- **Tag System**: Organize tasks with customizable tags
- **Responsive Design**: Bootstrap-powered interface that works on all devices
- **Sidebar Navigation**: Easy navigation between home and tags pages

## Pages


- **Home** (`/`): Display all tasks with completion status, creation date, deadlines, and tags
- **Task Management**: Create, update, and delete tasks
- **Tag List** (`/tags/`): View all tags with management options
- **Tag Management**: Create, update, and delete tags
